# 猜剪影（Guess Silhouette）

一个**完全离线**的 Windows 桌面小工具，用于动漫社活动现场投影互动：

> 把角色图放进文件夹 → 双击 `猜剪影.exe` → 随机显示黑色剪影让观众猜 → 按空格揭晓原图和角色名 → 再按空格出下一题 → 一轮内不重复。

角色剪影由**本地 AI 模型（isnet-anime）+ 传统算法（透明 / 纯色 / 渐变 / GrabCut）双保险**自动生成，全程不联网、不上传、不需要安装 Python。

## 特性

- **一键启动**：Releases 下载解压即用，双击 exe 就能跑
- **AI 抠图**：内置 isnet-anime 本地模型（ONNX，CPU 约 1~2 秒/张，仅在添加图片时运行一次，游戏现场零计算）
- **传统兜底**：AI 不可用或效果异常时，自动降级为四档传统抠图（透明 alpha / 纯色 Lab 色距 / 渐变多项式拟合 / GrabCut）
- **投影友好**：启动即全屏、隐藏鼠标光标、统一 1920×1080 画布、角色高度归一化、深色角色自动加浅色描边
- **手动修正**：快速选择（魔棒）/ 画笔 / 矩形框选，修正窗口全屏 + 滚轮缩放
- **增量缓存**：处理结果自动缓存，换图 / 改图 / 缓存损坏自动重新生成，算法升级自动整体重算

## 快速开始

到 [Releases](https://github.com/FokXuFok/guess-silhouette/releases) 下载（均已内置 AI 模型，解压即用）：

| 资产 | 说明 |
|---|---|
| `guess-silhouette-folder-vX.Y.Z.zip` | **推荐**。解压后双击 `猜剪影\猜剪影.exe`，启动约 1~5 秒 |
| `guess-silhouette-portable-vX.Y.Z.zip` | 便携单文件版，首次启动稍慢（约 10 秒，需解压依赖） |
| `guess-silhouette.exe` | 裸单文件（高级用户）：需自行把仓库里的 `models/isnetis.onnx` 放到 exe 旁的 `models\` 目录 |

系统要求：Windows 10 / 11（64 位），无需联网。

## 使用方法

1. 把角色图放进 `图片\` 子文件夹（首次运行自动创建；也可以在主页面点【添加图片】直接从电脑多选导入）
2. 双击 `猜剪影.exe`，等它自动生成剪影
3. 主页面点【开始】进入游戏（自动全屏）

| 按键 | 作用 |
|---|---|
| 空格 | 揭晓答案（黑底原图 + 角色名）→ 再按一次出下一个黑影，循环 |
| →（右方向键） | 直接跳到下一个黑影 |
| Esc 或右上角【结束本轮】 | 结束本轮回主页面 |
| F11 | 全屏开关 |
| Alt+F4 | 退出程序 |

展示规则：一轮内图片**不重复**；全部展示完后显示"本轮已全部展示完毕"，按空格 / Esc 回主页面可再开一轮。

### 活动当天建议

- 提前一天把图片准备好（文件名 = 角色名），在活动电脑上跑一遍 `--cli` 质检或逐张检查剪影
- 效果差的图用【修正这张】修一下或直接换掉，准备几张备用图
- 投影分辨率建议 1920×1080；没有键盘可用无线键盘或翻页笔

## 图片准备规范

1. **文件名就是角色名**：`漩涡鸣人.png` → 答案就是"漩涡鸣人"；不要用 `1.png`、`2.png`
2. **优先透明背景 PNG**：零处理，效果最好
3. **单人立绘最合适**：一个角色、居中、背景简单；纯色或简单渐变背景也行（自动去背）
4. **复杂背景**：自动效果会差一些，可用内置修正工具修，或提前用其他工具抠好
5. **分辨率别太低**：建议短边 ≥ 600px；缩略图级素材（350px 左右）抠图质量明显下降
6. **避免脸部特写 / 角色撑满画面**：剪影玩法需要可辨认的轮廓（半身 / 全身）；特写图剪影是一整块，建议换图
7. **支持格式**：PNG、JPG、JPEG、WEBP、BMP

## 手动修正

点【修正这张】打开全屏修正编辑器（红色 = 被去掉的背景）：

| 工具 | 操作 |
|---|---|
| 快速选择（魔棒） | 点一下背景残留**整片去掉**；点一下被误删的角色**整片找回**（按颜色容差自动扩展，容差可调） |
| 画笔擦除 / 恢复 | 左键 = 当前工具，右键 = 临时反向；带笔刷大小光标预览圈 |
| 矩形框选 | 框住主体后重新跑 GrabCut |
| 视图缩放 | 滚轮缩放（以鼠标为锚）、中键拖动平移、Ctrl+0 复位，放大后可逐像素精修 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |

支持容差、边缘羽化滑块；保存后立即生效并可跳到下一张待修图。现场不用修，活动前搞定即可。

## 抠图原理

程序按背景复杂度自动分档，全部本地运行：

| 档 | 适用 | 方法 |
|---|---|---|
| AI | 动漫立绘 / 截图（推荐） | isnet-anime 本地 ONNX 推理 + 蒙版清理（去碎片、填洞、平滑），异常自动回落 |
| 透明 | 透明背景 PNG | 直接读 alpha 通道，零处理 |
| 纯色 | 白底 / 纯蓝 / 纯绿等 | 边缘估计背景色 + Lab 色距 + 只去边缘连通背景 |
| 渐变 | 上浅下深等渐变背景 | 边缘采样拟合背景模型，逐像素比较 |
| 复杂 | 带纹理 / 简单场景 | GrabCut（512px 降采样提速），空洞自动填实；其他档效果差时也用它兜底 |

剪影生成：主体按高度归一化居中到 1920×1080 画布；猜谜图为白底黑影，揭晓图为黑底原图 + 角色名（深色角色自动加浅色描边防吞）。

## 从源码运行

```bash
pip install -r requirements.txt

python guess.py                              # 打开界面（等价于双击 exe）
python guess.py --cli                        # 命令行批处理 + 质检报告，不开界面
python guess.py --cli --folder "D:\我的图"    # 指定图片文件夹
python guess.py --cli --force                # 强制重新生成全部缓存
```

`--cli` 会输出每张图的档位（AI / 透明 / 纯色 / 渐变 / 复杂）和"建议修正"清单，适合活动前批量检查。

### 打包 exe

```bash
build.bat        # 单文件：dist\猜剪影.exe
build.bat dir    # 文件夹模式：dist\猜剪影\（启动更快，推荐现场用）
```

打包脚本会自动把 `models/isnetis.onnx` 复制到输出目录；模型不存在时生成不含 AI 的版本（传统四档照常工作）。

### 测试

```bash
python -m pytest tests -q
```

覆盖：分档抠图质量（合成图对拍真实蒙版）、缓存增量与损坏自愈、坏图跳过、随机抽题、图片入库、配置读写、界面冒烟（主页面 → 添加图片 → 开始 → 空格循环 → 完毕页 → 手动修正）。

## 配置 config.json

首次运行自动生成在程序目录，按需修改（改完重启生效）：

| 字段 | 默认 | 说明 |
|---|---|---|
| tolerance | 20 | 传统抠图容差（Lab 色距），越大去背景越狠 |
| feather_px | 1.5 | 边缘羽化像素 |
| reveal_mode | black | 揭晓背景：black / darkgray / original（原图背景） |
| dark_protect | true | 深色角色揭晓时自动加细浅色描边 |
| canvas_w / canvas_h | 1920 / 1080 | 统一画布尺寸（对齐投影分辨率） |
| subject_ratio | 0.82 | 角色占画布高度比例（统一大小） |
| guess_bg / silhouette_color | #FFFFFF / #000000 | 猜谜图背景与剪影颜色 |
| ai_matting | true | AI 抠图优先（缺失模型时自动降级） |

## 缓存与日志

- 处理结果缓存在 `缓存\<图片文件夹名>\`：`state.json`（每张图的档位、质量标记、是否已人工确认）+ 猜谜图 / 揭晓图 / 蒙版 PNG
- 换图、改图、缓存损坏自动重新生成；删掉 `缓存\` 可全量重来
- 运行日志：`缓存\运行日志.log`

## 代码结构

```text
guess.py            入口（界面 / CLI 双模式）
build.bat / build.py  打包脚本
app/
  ui.py             主界面：主页面、游戏页、展示完毕页、快捷键、全屏
  editor.py         手动修正编辑器：快速选择 / 画笔 / 矩形框选 / 缩放 / 撤销
  imaging.py        抠图核心：分档处理 + 剪影、揭晓图生成
  segmentation.py   AI 抠图（isnet ONNX 本地推理，可选自动降级）
  library.py        添加图片：多选复制进库、重名与重复内容处理
  store.py          缓存与状态管理（state.json）
  deck.py           随机抽题（一轮不重复 / 展示完即止）
  config.py         配置读写
  paths.py          路径工具
tests/              pytest 测试（合成图 + 界面冒烟）
```
